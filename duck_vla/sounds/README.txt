Duck VLA Sound Files

Place .wav files in this directory with the following naming convention:

happy_N.wav - where N is a number (1, 2, etc.)
sad_N.wav - where N is a number (1, 2, etc.)
curious_N.wav - where N is a number (1, 2, etc.)
afraid_N.wav - where N is a number (1, 2, etc.)
hello_N.wav - where N is a number (1, 2, etc.)
goodbye_N.wav - where N is a number (1, 2, etc.)
neutral_N.wav - where N is a number (1, 2, etc.)
error_N.wav - where N is a number (1, 2, etc.)
success_N.wav - where N is a number (1, 2, etc.)
processing_N.wav - where N is a number (1, 2, etc.)
warning_N.wav - where N is a number (1, 2, etc.)

Example: happy_1.wav, happy_2.wav, sad_1.wav
